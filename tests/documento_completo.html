Introducción a Java

Java es un lenguaje orientado a objetos y multiplataforma con soporte completo para caracteres acentuados: á, é, í, ó, ú, ñ, ¿¡.

Características principales

  • Portabilidad mediante la JVM
  • Gestión automática de memoria
  • Biblioteca estándar robusta (java.net, java.nio.file)

Ejemplo de código

public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola desde Java 17!");
    }
}

Write once, run anywhere — Principio fundamental de la plataforma Java.
